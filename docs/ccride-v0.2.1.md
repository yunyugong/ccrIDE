# ccrIDE v0.2.1

## 工作区

左侧工具栏与文件树、中央编辑器、底部问题/输出/终端/调试。保留原生 ImGui docking：标签拖动、浮动、拆分、调整宽高与持久化布局。旧布局不强制重置，视图菜单可恢复默认布局。

文件树使用 Windows Shell 的文件关联图标，缓存系统图标纹理，只为可见行加载；没有关联时回退系统文件类型图标，刷新树时清缓存。不修改系统默认应用。

构建日志进入输出；目标进程 stdout/stderr、标准输入与运行统计进入终端。调试页保留检查、断点和日志，在检查区并排显示变量和调用栈。设置分为六类，窄窗口使用分类下拉框。

## 补全

普通单词与未限定成员查询使用当前命名空间、using 指令与 using 声明的作用域。闭合块/函数中的导入不会泄漏；头文件翻译单元的光标位置映射到当前文档对应行。显式 std::cin 与局部同名变量保持合法候选。

注释提取保留块注释段落，合并 Doxygen 分组说明与行末注释，过滤分组标记，并移除 120 行上限。建立分组索引，避免为每个候选重复扫描整个翻译单元。

候选记录声明文件、行号及各处注释。保留命名空间重开、类型前置声明等多个声明位置，详情中可切换来源；完整路径通过悬停查看。长注释滚动阅读，HTTP(S) 链接可点击。来源切换后文档从顶部显示，并恢复编辑焦点。
