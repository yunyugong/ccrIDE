# clangd 插件 1.1.0

需要 ccrIDE 0.3.5 或以上。核心不依赖 clangd；安装插件后由独立进程提供语义服务，UI DLL 仍在 IDE 进程内执行。

## 安装与配置

在“插件 → 安装本地插件”选择 clangd-v1.1.0.zip。离线包附带官方 Windows x64 clangd 23.1.0、资源头文件和许可证；无需另外安装 LLVM。插件设置位于“插件 → clangd 设置”，保存到 data/plugins/clangd/settings.json。

- clangd 路径：留空先查找插件内 toolchain/bin/clangd.exe，再查找 PATH；也可填写外部版本的完整路径。
- 编译数据库目录：填写 compile_commands.json 所在目录，或留空由 clangd 自动查找。CMake 工程可在支持的生成器上配置 CMAKE_EXPORT_COMPILE_COMMANDS=ON。
- 无数据库时的编译参数：默认 -std=c++17，可填标准、宏、包含目录；路径有空格时使用引号。当前 IDE 选择的 g++ 用于单文件编译命令及系统头文件发现；切换编译器会重启服务。
- 内存：默认 1024 MiB，可设置 128–4096 MiB。上限过低可能使服务退出。
- 后台索引：默认关闭；需要工程跨文件信息时可开启，并提供编译数据库。大型工程会增加资源占用。

有数据库时以实际编译命令为准，插件不替换其中的编译器或参数。query-driver 仅允许 IDE 已选定的编译器路径；若数据库使用其他驱动，应调整 IDE 选项或数据库。Windows 本地路径支持中文、空格和 URI 转义，UNC 路径暂未验证。

## 首版功能

同步已有路径的文档打开、完整内容变更和关闭；补全支持模板、别名和标准库类型，返回类型/签名；诊断进入现有问题面板，遵循自动语法检查开关；Ctrl+B / Ctrl+点击请求定义。include 路径补全保留原实现。服务不可用、超时或卸载时回退轻量补全与基础导航。

文档、光标或路径改变后丢弃旧结果；Esc 关闭后不重新弹出旧候选。接受补全使用服务返回的替换范围，支持单次撤销。UTF-8 编辑内容与 LSP UTF-16 位置双向转换。文档刚变更时等待该版本解析完成，避免把过期预编译头的词法结果当成模板语义成员。

clangd 由 Windows Job 管理；停用、卸载、退出或协议超限时回收子进程。提供“重启 clangd”菜单，故障后不无限自动重启。消息、队列、每帧消费和资源均有限制；这不是权限沙箱。

## 当前边界

- 未命名文件仍使用轻量补全；语义同步上限每文件 2 MiB、最多 32 个文档/共 16 MiB。
- 首版只接入补全、诊断、定义跳转；已新增语义重命名预览，见 workflows.md；引用查找、格式化、代码动作和多目标工程管理未实现。
- 不执行补全中的额外文件编辑或 snippet；函数接受后按现有习惯插入括号。自动 include 关闭。
- 补全注释插件目前显示轻量补全的详情；clangd 候选尚未连接文档解析、来源选择与可点击注释功能。
- 宏、条件编译和跨翻译单元结果取决于数据库、头文件与索引；没有数据库不代表已得到真实工程配置。
- 当前验证版本为随包 23.1.0；协议要求 UTF-16 位置和带版本的诊断，未承诺兼容所有旧版本服务。

## 验证

自动检查包含 Content-Length 分片/连帧、异常长度、Unicode 位置与 URI；真实 clangd 上验证嵌套 vector、模板别名成员、文档变更、诊断、定义及服务退出与重启；另以真实编译数据库检查包含目录、条件编译宏和跨头文件定义跳转。

宿主回归检查过期结果、光标移动、Esc、替换/撤销和不可用回退。额外将最终插件 ZIP 安装到中文临时目录，检查实际 DLL、随包服务、接受补全、诊断、跳转、异常退出、重载和卸载。以上范围不代表完整大型工程基准已通过。
