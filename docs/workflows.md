# 编辑、竞赛测试与恢复（0.3.5）

## 多光标和列编辑

Alt+单击添加光标；Alt+Shift+拖动建立矩形选区，短行截断到行尾，不插入虚拟空格。可同时输入、删除、换行、缩进、复制/剪切和粘贴。粘贴的行数等于光标数时逐行分配，否则每处插入全部文本。方向键移动所有光标，Shift 扩展各自选区，Esc 返回单光标。一次批量输入可整体撤销；撤销后回到单光标。多光标模式不弹语义补全，不为每个光标执行智能括号或智能缩进。

## 符号重命名

需要 clangd 插件 1.1.0；通过“编辑 → 符号重命名”输入 ASCII C++ 标识符，请求语义预览。由 clangd 判断引用与遮蔽作用域，不以普通字符串替换代替。预览按文件列出修改后内容，应用到编辑标签后仍未保存；用户检查后自行保存，各文件可分别撤销。

预览期间文件发生变化则拒绝应用。首版不支持文件创建/删除/重命名等 WorkspaceEdit 资源操作，最多 5000 处文本编辑；跨工程结果取决于编译数据库及索引覆盖。仍需审阅预览，不承诺对所有 C++ 工程完整重构。

## 样例与 Subtask

“测试 → 样例、Subtask 与对拍”独立于插件使用。当前标签为待测解；未保存时先保存源码。配置写入 data/tests.json，运行产物放在 data/runs 下的唯一目录，不覆盖旧程序。

样例可编辑名称、输入、期望输出、所属组及启用状态。可导入同一目录下的 .in / 同名 .out。比较策略可显式选择严格字节比较或忽略空白的 Token 比较，后者不做浮点容差判断。每个样例显示判定、耗时、观测峰值、首个差异及 stderr。界面最多显示各输出前 4 KiB；界面保留最近 1000 条结果，完整输出在归档中。

Subtask 使用组内所有已启用样例通过才得分的规则，可声明前置组依赖。未运行的空组、未知依赖、循环依赖不得分；不支持部分分、交互题或自定义检查器。

标准版本、优化、警告与附加参数取自设置，不运行自定义命令模板。时间、内存、总输出限制沿用运行设置；每例 stdin 写完关闭，工作目录为解法源码目录。测试不传递普通交互运行的命令行参数、环境覆盖或自定义 cwd。

判定区分 AC、WA、CE、RE、TLE、MLE、OLE、取消、启动失败和执行失败。MLE 依据 Windows Job 内存通知；不能仅凭非零退出码推断内存超限。每批最多 1000 样例，归档写入上限 512 MiB；超限明确停止，不静默裁剪后继续判为正确。

## 对拍与复现

填写参考解与生成器源码；当前标签为待测解。三程序全部编译成功后，逐轮执行生成器 → 参考解 → 待测解 → 比较。生成器从第一个 argv 参数接收种子，用 stdout 生成输入，用户应实现种子决定性的生成器。

首个失败停止；GEN-/REF- 前缀区分生成器和参考解故障。归档保留源码快照、编译器和参数、种子/轮次、编译日志、每例输入/期望/实际输出/stderr 和结果。将 case-N 目录填入重放框，即可直接将失败输入与期望输出导入为样例，不重新随机生成。通过快照可核对或重建当时程序。

对拍最多 10000 轮，不提供交互式对拍、自动缩减反例或多线程生成器调度。运行进程受限，但并非恶意代码沙箱。

## 所有标签恢复

每三秒保存所有标签到 data/recovery/workspace.json，包含空的未命名标签、未保存内容、原路径、光标/选区、滚动、编码和断点。正常退出也保存快照。先写临时文件并刷新，再原子替换；保留上一代 .previous。损坏时尝试上一代并明确提示，写入失败保留旧文件并显示错误。

启动恢复会列出可选标签；恢复内容只生成未命名副本，不写回原源码。用户确认前不覆盖待恢复快照。旧 autosave.cpp 仍可导入，消费后保留 .migrated 文件。恢复不包含撤销历史、所有插件会话或测试进程状态；最后三秒内尚未完成的更改仍可能丢失。

## 仍未完成的架构项

任意原生 DLL 的进程隔离与完整权限系统尚未完成。AI 与 clangd 的服务进程隔离了相关耗时工作，但 UI DLL 仍共享宿主内存，能够绕过宿主接口访问文件、网络和进程。完整修复需要迁移 UI 扩展协议、操作代理与系统级权限执行；清单权限或 Windows Job 不能代替此工作。

性能比较见 performance.md；核心操作基准不等同于冷启动、空闲 CPU、整机压力和大型工程语义基准。
