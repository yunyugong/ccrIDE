# 自定义设置（v0.3.7.1）

从菜单或活动栏打开“设置”，可按关键词搜索分类。设置分为编译器与构建、代码辅助、运行与调试、外观与颜色、插件、快捷键、编辑习惯、备份与偏好八类。窄窗口使用分类下拉框，长标签自动换行；内容单独滚动，底部保存按钮固定。

修改后可立即预览，点击“保存设置”写入本机 settings.json；关闭窗口仍保留当前预览，退出前请点击保存设置以保留偏好。原有主题、颜色和快捷键继续保留。缺少新字段的旧配置使用默认值，导入和读取时会收敛数值范围。

Tab 宽度同时用于绘制、鼠标命中、上下移动、退格、缩进提示线和多光标输入。切换设置不会重新格式化已有文本，只影响显示和后续输入。隐藏行号后仍保留折叠、断点区域；隐藏活动栏或工具栏后仍可从主菜单进入设置。

自动补全关闭后，Ctrl+Space 仍可手动请求补全。最少字符数仅控制普通单词的自动弹出，成员、命名空间和 include 补全可直接触发。列表会根据可用屏幕高度自动减少显示行数，弹窗宽度始终不超过屏幕。普通代码补全保持内置，注释内容仍由独立插件提供。

恢复间隔控制已有的全部标签恢复快照，不会自动覆盖源码；关闭 IDE 时仍按原有流程保存会话。设置更长间隔会扩大意外退出时可能损失的编辑范围。

## 预设与偏好文件

“紧凑竞赛”调整为编辑字号 16、界面字号 14、紧凑布局、行距 115%；“舒适阅读”使用 20、17、宽松布局、150%。两种预设只修改这四个值，保留配色、快捷键与工具链。

导出的 JSON 包含编辑、外观、代码辅助、恢复间隔与快捷键，不包含编译器/GDB 路径、运行环境、会话源码、停用插件列表或插件私有配置。使用专用的 format=ccrIDE.preferences、schema=1 格式；导入前校验，格式/类型错误或超过 1 MiB 时不修改当前偏好，合法但超出范围的数值会收敛。

“恢复默认偏好”恢复上述偏好、原有编辑器配色及快捷键。编译器路径、构建与运行选项、环境覆盖和插件启停状态保留。导入、应用预设和恢复默认后，点击保存设置即可保留。

插件 ABI 保持 v3，AI/clangd 1.2.0 与补全注释 1.0.0 的独立安装包继续兼容。
