# ccrIDE v0.2.0

2026-10-31。当前产品名为 ccrIDE，IDE.py 只保留在版本沿革中作为最初原型。

## 本次交付

默认快捷键：F10 仅编译，F11 编译并运行，F12 运行当前文件最后一次成功编译的程序；F5 开始调试，暂停后 F5 继续；Ctrl+B 跳转定义。原有用户自定义快捷键继续保留。工具栏和菜单分别提供编译、编译运行、运行入口。

发布产物使用 `ccrIDE-v0.2.0-build<日期时间>.exe`，放在 build/releases。build.ps1 和 CMake 都发布独立文件，不覆盖之前的 MiniCPP.exe 或已有版本。版本与构建时间出现在标题、“关于”、构建输出和发布 JSON 中。CMake 的私有链接文件使用 .bin；最新发布索引是 latest-build.json。

用户代码也改为独立产物：源文件旁 `.ccrIDE-build/<源文件>-v<时间标识>.exe`，每次编译保留旧 EXE。数据目录的 build-artifacts.json 保存每个源文件最近一次成功编译的目标。F12 不保存或重新编译当前修改，控制台会说明运行的是已编译版本。失败构建不替换最近成功产物。

行侧红杠表示相对上次保存新增或修改的行，绿杠表示原有或已保存行。保存、撤销与重做会更新标记。红绿杠、折叠、断点与诊断各有位置，红绿杠的颜色可配置。大范围重写使用有计算上限的行比较，无法确定的变化区域保守标红。

## 基础调试

Ctrl+点击行号或编辑器右键设置/移除断点，断点随有路径的标签会话保存。F5 为当前文件生成独立的 -g -O0 调试版本；无断点时暂停在 main。调试面板显示变量、调用栈、表达式求值及可复制的日志，提供步入、步过、继续、暂停和停止。暂停时可以调整断点；运行中修改断点会提示先暂停。

GDB 路径可配置，留空使用 g++ 同目录下的 gdb.exe。标准输入来自设置指定的文件，留空使用空文件（EOF），避免程序与 MI 协议共用交互输入。GDB 与被调试进程共享统一执行器的 Job，停止或退出会清理进程组。命令有超时，启动失败、协议异常或调试器异常退出会保留具体错误。

Windows 本地目标在运行时不一定处理 MI interrupt，暂停因此通过已持有的目标进程句柄请求原生调试中断。随包 GDB 采用 Windows 本地路径编码，进出协议时与编辑器 UTF-8 分别转换；已测试中文和空格路径。不可由该工具链字符集表示的路径仍可能受限。

当前是基础单目标调试器，未实现线程管理、寄存器、反汇编或交互调试 stdin。调试期间修改源码后，需要重新启动调试对应新的符号。普通运行的墙钟和内存设置不直接套用到暂停中的 GDB 会话；调试输出、命令等待和进程组仍有控制。

## 验证范围

- 实际 GDB：断点、变量、求值、步入、步过、栈帧、输入文件、正常退出、运行中暂停/停止，中文和空格目录。
- GDB 故障：工具不存在、目标不存在、协议损坏、无响应命令超时；停止后回收进程。
- 编译动作：仅编译不会自动运行，F12 使用上次成功产物，重复编译生成不同文件，预先存在的 main.exe 保持原内容。
- 行标记：插入、修改、删除、保存、撤销、重做、大范围变化的有界比较。
- 配置及旧编辑功能回归、暗/亮与窄窗口布局；便携包将继续验证移动目录后的编译与调试。

样例测试、对拍、多光标和完整插件隔离仍在后续清单中，本版本没有宣称这些能力已完成。
